الجلسة الخامسة — معالجة الصورة والرؤية الحاسوبية

1.ipynb — Raw Pixel Feature Extraction

١ ما هي "استخراج الميزات" Feature Extraction؟

في تعلم الآلة ومعالجة الصورة، لا يمكننا إدخال الصورة مباشرةً إلى النموذج الرياضي لأنها مصفوفة ثنائية الأبعاد (أو ثلاثية). نحتاج إلى تحويلها إلى متجه رقمي أحادي البُعد يسمى متجه الميزات (Feature Vector).

الفكرة الأساسية: كل صورة = مجموعة من الأرقام (قيم البيكسلات). يمكننا أخذ هذه الأرقام وتسطيحها (flatten) في خط واحد طويل وإعطاءها للنموذج.

أبسط طريقة لاستخراج الميزات هي أخذ قيم البيكسلات مباشرةً دون أي معالجة — تُعرف بـ Raw Pixels.

٢ قراءة الصورة وفحص أبعادها

import cv2
import numpy as np

img = cv2.imread('image.jpg', 0)
img.shape
(400, 400)

شرح السطر بسطر:

🔹 import cv2

استيراد مكتبة OpenCV — وهي مكتبة مفتوحة المصدر متخصصة في معالجة الصورة والرؤية الحاسوبية. تستخدمها الشركات الكبرى في تطبيقات مثل التعرف على الوجوه وقيادة السيارات ذاتياً.

🔹 import numpy as np

استيراد مكتبة NumPy للعمل مع المصفوفات والعمليات الرياضية. الصور في الكمبيوتر ما هي إلا مصفوفات أرقام، وNumPy هي الأداة الأقوى للتعامل معها.

🔹 cv2.imread('image.jpg', 0)

المعامل الأول: مسار الصورة — 'image.jpg'
المعامل الثاني: 0 يعني قراءة الصورة بـ تدرج الرمادي (Grayscale) أي بُعد واحد فقط.
لو وضعنا 1 بدلاً من 0 لقرأنا الصورة ملونة (BGR — ثلاثة أبعاد).

🔹 img.shape

تعرض أبعاد المصفوفة. النتيجة (400, 400) تعني:

القيمةالمعنى
400 (الأول)عدد الصفوف = الارتفاع بالبيكسل
400 (الثاني)عدد الأعمدة = العرض بالبيكسل

إذاً الصورة 400×400 بيكسل = 160,000 بيكسل إجمالاً.

٣ تغيير حجم الصورة (Resize)

img = cv2.resize(img, (64, 64))
img.shape
(64, 64)

لماذا نُصغِّر الصورة؟

⚠️ الصورة الأصلية 400×400 = 160,000 بيكسل. لو استخدمناها مباشرة في نموذج تعلم الآلة:
— سيكون المتجه كبيراً جداً (160,000 عنصر لكل صورة)
— الحساب سيكون بطيئاً جداً
— خطر الـ Overfitting يزداد

🔹 cv2.resize(img, (64, 64))

المعامل الأول: الصورة الأصلية
المعامل الثاني: الحجم الجديد (عرض، ارتفاع) = (64, 64)
ملاحظة: في resize، الترتيب هو (عرض، ارتفاع) — عكس shape التي تعطي (ارتفاع، عرض)!

الآن الصورة 64×64 = 4,096 بيكسل فقط. تقليل كبير!

٤ تسطيح الصورة (Flatten) — إنشاء متجه الميزات

features = img.flatten()
print(features.shape)
(4096,)

🔹 img.flatten()

هذه العملية تحوّل الصورة من مصفوفة ثنائية الأبعاد (64 × 64) إلى مصفوفة أحادية البُعد (4096 عنصر).

تصور بصري:
مصفوفة 64×64:
[[ 120, 85, 90, ... ], [ 100, 95, 88, ... ], ...]

بعد flatten:
[ 120, 85, 90, ..., 100, 95, 88, ..., ]
كل البيكسلات في صف واحد طويل (4096 رقم)

📐 الحساب الرياضي:

64 × 64 = 4,096 — هذا هو طول متجه الميزات.

✅ الآن لدينا متجه ميزات بطول 4096 يمثل الصورة كاملة. يمكننا إدخاله مباشرةً في أي خوارزمية تعلم آلة مثل Logistic Regression أو SVM أو KNN.

٥ مميزات وعيوب طريقة البيكسلات الخام

الجانبالتفصيل
✅ بساطةلا تحتاج إلى أي خوارزمية معقدة — مجرد flatten
✅ سرعةالعملية فورية ولا تستهلك وقتاً للحساب
❌ حساسة للإضاءةنفس الجسم بإضاءة مختلفة يعطي بيكسلات مختلفة تماماً
❌ حساسة للإزاحةالجسم في يمين الصورة أو يسارها يعطي متجهات مختلفة
❌ حساسة للتدويرالجسم المدور يبدو مختلفاً تماماً رياضياً
❌ حجم كبيرصورة 100×100 = 10,000 ميزة — قد يكون كثيراً
⚠️ لماذا نحتاج طرقاً أفضل؟
البيكسلات الخام لا تفهم "المعنى" في الصورة. لذلك طُوِّرت طرق مثل HOG وLBP وORB التي سنشرحها في الملفات التالية.

٦ ملخص الكود كاملاً

import cv2
import numpy as np

# الخطوة 1: قراءة الصورة بالرمادي (0 = grayscale)
img = cv2.imread('image.jpg', 0)
# img.shape → (400, 400) — صورة 400×400 بيكسل

# الخطوة 2: تصغير الصورة لتوحيد الحجم
img = cv2.resize(img, (64, 64))
# img.shape → (64, 64) — الآن 64×64 بيكسل

# الخطوة 3: تسطيح الصورة إلى متجه أحادي البُعد
features = img.flatten()
# features.shape → (4096,) — متجه ميزات جاهز للنموذج
print(features.shape)
🎯 الخلاصة: هذا الكود يأخذ صورة 400×400، يصغرها إلى 64×64، ثم يحولها إلى متجه رقمي بطول 4096 — يمثل الصورة كميزات خام جاهزة لتعلم الآلة.
