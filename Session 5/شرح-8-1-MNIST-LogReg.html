١ ما هو مجموعة بيانات MNIST؟

MNIST = Modified National Institute of Standards and Technology

هي مجموعة البيانات الأشهر في مجال تعلم الآلة ومعالجة الصورة. تحتوي على صور يدوية للأرقام من 0 إلى 9.

٣ خط أنابيب تعلم الآلة الكامل

from tensorflow.keras.datasets import mnist
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score
import matplotlib.pyplot as plt

(x_train, y_train), (x_test, y_test) = mnist.load_data()

# 1) تسطيح الصور
x_train_flat = x_train.reshape(60000, 28 * 28)
x_test_flat  = x_test.reshape(10000, 28 * 28)
x_train_flat.shape  # (60000, 784)
(60000, 784)

🔹 x_train.reshape(60000, 28 * 28)

تحويل شكل المصفوفة من (60000, 28, 28) إلى (60000, 784):
— 60,000 صورة
— كل صورة 28 × 28 = 784 بيكسل في صف واحد
الانحدار اللوجستي يحتاج كل عينة كمتجه أحادي البُعد. 
# 2) تطبيع القيم من 0-255 إلى 0-1
x_train_flat = x_train_flat / 255.0
x_test_flat  = x_test_flat  / 255.0

🔹 التطبيع (Normalization)

قسمة كل قيمة على 255 يحوّل النطاق من [0, 255] إلى [0.0, 1.0].

⚠️ لماذا التطبيع مهم جداً؟
— معظم خوارزميات تعلم الآلة تعمل بشكل أفضل مع قيم صغيرة (0-1)
— تمنع هيمنة الميزات ذات القيم الكبيرة
— تُسرّع التقارب أثناء التدريب
— بدون تطبيع، الانحدار اللوجستي قد لا يتقارب أبداً!

٤ ما هو الانحدار اللوجستي؟

على الرغم من اسمه، الانحدار اللوجستي هو في الواقع خوارزمية تصنيف وليس انحداراً! يُستخدم للتنبؤ بأي فئة تنتمي إليها العينة.

كيف يعمل؟
— يحسب مزيجاً خطياً من الميزات: z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
— يُمرّر z عبر دالة sigmoid: σ(z) = 1/(1 + e⁻ᶻ) → ترجع قيمة بين 0 و 1
— في التصنيف متعدد الفئات (مثل MNIST): يُنشئ نموذجاً لكل فئة ويختار الأعلى احتمالاً
— يتعلم الأوزان (weights) بتقليل خطأ Cross-Entropy 
# 3) إنشاء النموذج
model = LogisticRegression(max_iter=1000)

# 4) تدريب النموذج
model.fit(x_train_flat, y_train)

🔹 LogisticRegression(max_iter=1000)

max_iter=1000: الحد الأقصى للتكرارات. الافتراضي 100 وهو أقل جداً لـ MNIST. بدون هذا، ستظهر رسالة تحذير: "Increase the number of iterations."
خوارزمية الحل الافتراضية: lbfgs — أسرع وأكثر كفاءة للبيانات الكبيرة.

🔹 model.fit(x_train_flat, y_train)

تدريب النموذج:

  • المُدخل الأول: مصفوفة الميزات (60,000 × 784)
  • المُدخل الثاني: مصفوفة التسميات (60,000 رقم من 0-9)
  • الخوارزمية تتعلم الأوزان المثلى لكل فئة

٥ التقييم والتنبؤ

# 5) تقييم النموذج
y_pred = model.predict(x_test_flat)
accuracy = accuracy_score(y_test, y_pred)
print("Accuracy:", accuracy)

# 6) تجربة صورة جديدة
index = 0
new_image = x_test[index]
new_image_flat = new_image.reshape(1, 28 * 28) / 255.0

prediction = model.predict(new_image_flat)

print("Predicted digit:", prediction[0])
print("Real digit:", y_test[index])

# 7) عرض الصورة
plt.imshow(new_image, cmap="gray")
plt.title(f"Predicted: {prediction[0]} | Real: {y_test[index]}")
plt.axis("off")
plt.show()

🔹 model.predict(x_test_flat)

تطبيق النموذج المدرَّب على بيانات الاختبار. ترجع مصفوفة من التنبؤات — رقم واحد (0-9) لكل صورة.

🔹 accuracy_score(y_test, y_pred)

حساب نسبة الدقة: عدد التنبؤات الصحيحة ÷ إجمالي التنبؤات

🔹 new_image.reshape(1, 28 * 28)

لماذا (1, 784) وليس (784,)؟
الـ 1 يمثل "عينة واحدة". النموذج يتوقع مصفوفة ثنائية الأبعاد: (عدد العينات, عدد الميزات). للتنبؤ بصورة واحدة نمررها كمصفوفة فيها صف واحد.

🔹 f"Predicted: {prediction[0]} | Real: {y_test[index]}"

f-string: طريقة Python لدمج متغيرات في نص. تعرض الرقم المتنبأ به والرقم الحقيقي في عنوان الصورة.
