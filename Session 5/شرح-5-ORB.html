١ ما هو ORB؟ وما معنى الاختصار؟

ORB = Oriented FAST and Rotated BRIEF

O
Oriented
موجَّه — مقاوم للدوران
FAST
Features from Accelerated Segment Test
خوارزمية سريعة لإيجاد النقاط المميزة
R
Rotated
مُدوَّر — لمقاومة الدوران
BRIEF
Binary Robust Independent Elementary Features
واصف ثنائي خفيف وسريع
قصة ORB: طُوِّر في OpenCV Labs عام 2011 كبديل مجاني وسريع لخوارزميتَي SIFT وSURF اللتين كانتا محميتَين ببراءات اختراع (مدفوعتَين). ORB مجانية الاستخدام وأسرع بكثير مع نتائج قريبة.

٢ كيف يعمل ORB؟ — مرحلتان

المرحلة الأولى: إيجاد النقاط المميزة (Keypoints) — باستخدام FAST

خوارزمية FAST تبحث عن نقاط مميزة بطريقة ذكية: تأخذ دائرة من 16 بيكسلاً حول نقطة مركزية، وتتحقق إذا كان:

  • N متواليات (عادةً 9) من الـ 16 بيكسل أفتح أو أغمق من المركز بمقدار معين
  • إذا نعم → هذه نقطة مميزة (Keypoint)

ORB يُضيف لـ FAST حساب الاتجاه (Orientation) لكل نقطة باستخدام العزم الشعاعي (Intensity Centroid)، مما يجعله مقاوماً للدوران.

المرحلة الثانية: وصف النقاط (Descriptors) — باستخدام BRIEF

بعد إيجاد النقاط المميزة، نحتاج "بصمة" لكل نقطة ليمكن مطابقتها في صور أخرى. BRIEF يعمل كالتالي:

  • يأخذ أزواجاً عشوائية من البيكسلات حول النقطة المميزة
  • يقارن كل زوج: إذا البيكسل الأول أكبر → 1، وإلا → 0
  • ينتج متجهاً ثنائياً بطول 256 بت
لماذا ثنائي (Binary)؟
المقارنة بين وصفَين ثنائيَّين تستخدم مسافة Hamming (عدد البتات المختلفة) وهي أسرع بكثير من المسافة الإقليدية المستخدمة مع SIFT.

٣ شرح الكود سطراً بسطر

import cv2

img = cv2.imread('person.jpg', 0)

orb = cv2.ORB_create()

# استخراج النقاط
keypoints, descriptors = orb.detectAndCompute(img, None)

# رسم النقاط
img2 = cv2.drawKeypoints(img, keypoints, None)

cv2.imshow('ORB Features', img2)
cv2.waitKey(0)
cv2.destroyAllWindows()

🔹 cv2.imread('person.jpg', 0)

قراءة صورة شخص بالرمادي. نستخدم person.jpg هنا (بدلاً من image.jpg) لأن ORB مناسب للكائنات الحقيقية ذات التفاصيل الكثيرة.

🔹 cv2.ORB_create()

إنشاء كائن ORB بالإعدادات الافتراضية. يمكن تخصيصه:
cv2.ORB_create(nfeatures=500) — أقصى عدد نقاط مميزة (افتراضي: 500)
cv2.ORB_create(scaleFactor=1.2) — عامل تحجيم الهرم
cv2.ORB_create(nlevels=8) — عدد مستويات الهرم
cv2.ORB_create(edgeThreshold=31) — حجم الحافة المُهمَلة

🔹 orb.detectAndCompute(img, None)

هذه الدالة تؤدي مرحلتَين دفعةً واحدة:

المرحلةالمخرجالوصف
detectkeypointsقائمة من كائنات KeyPoint — كل واحد يحمل: الموقع (x,y)، الحجم، الزاوية، القوة
computedescriptorsمصفوفة NumPy شكلها (N, 32) — N = عدد النقاط، 32 بايت = 256 بت لكل نقطة

المعامل الثاني None يعني: لا توجد قناع — ابحث في الصورة كاملة.

🔹 cv2.drawKeypoints(img, keypoints, None)

رسم النقاط المميزة على الصورة. None في المعامل الثالث تعني: أعطنا صورة جديدة (لا تعدّل على الأصلية). يمكن إضافة علامات أكبر: 

img2 = cv2.drawKeypoints(img, keypoints, None,
                           flags=cv2.DRAW_MATCHES_FLAGS_DRAW_RICH_KEYPOINTS)
# سيرسم دوائر بحجم كل نقطة واتجاهها

٤ تفصيل كائن KeyPoint

# مثال على طباعة تفاصيل أول نقطة
kp = keypoints[0]
print("الموقع:", kp.pt)        # (x, y) بالبيكسل
print("الحجم:", kp.size)      # قطر المنطقة ذات الصلة
print("الزاوية:", kp.angle)   # اتجاه النقطة بالدرجات
print("القوة:", kp.response)  # قوة النقطة (كلما كبرت كلما كانت أوضح)

octaveمستوى الهرم الذي وُجدت فيه — لمقاومة التحجيم

٦ الكود الكامل مع الشرح

import cv2

# الخطوة 1: قراءة الصورة بالرمادي
img = cv2.imread('person.jpg', 0)

# الخطوة 2: إنشاء كاشف ORB
orb = cv2.ORB_create()

# الخطوة 3: اكتشاف النقاط المميزة وحساب واصفاتها
# keypoints: قائمة نقاط (موقع، حجم، زاوية)
# descriptors: مصفوفة (N, 32) — 32 بايت = 256 بت لكل نقطة
keypoints, descriptors = orb.detectAndCompute(img, None)

# الخطوة 4: رسم النقاط على الصورة
img2 = cv2.drawKeypoints(img, keypoints, None)

# الخطوة 5: عرض النتيجة
cv2.imshow('ORB Features', img2)
cv2.waitKey(0)
cv2.destroyAllWindows()
